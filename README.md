# AI Travel Guide using Murf AI

An AI-powered travel guide that generates travel information and multilingual audio guides using Google Gemini and Murf AI.

## Features

- AI-generated travel guides
- Multiple destinations
- English, Hindi, Tamil and Telugu
- Male and Female voices
- Audio guide generation
- Live web deployment

## Technologies

- HTML
- CSS
- JavaScript
- Python Flask
- Google Gemini AI
- Murf AI
- Render
- Vercel
